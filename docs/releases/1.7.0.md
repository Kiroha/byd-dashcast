# DashCast 1.7.0

**The first stable release since 1.5.4** — and a milestone: the DashCast codebase has crossed **50% Kotlin**. Kotlin files now outnumber Java. 1.7.0 consolidates the entire 1.6.x beta series into a single, tested, **Latest** release.

> This release **is** merged into `main` and marked as the repository's **Latest** stable release. Testers who were on the `1.6.x` beta channel can move to it directly; users still on `1.5.4` get every feature listed below at once.

## 🏆 Milestone — majority Kotlin

The migration from Java to Kotlin passed the halfway mark. Converted so far, each as a build-and-test-green lot: the voice package, the bug reporter (`report/`), the navigation rail, the cluster DPI / display / mirror layers, most of `infrastructure/`, the app lifecycle, and a batch of pure-logic policy classes backed by unit tests. The Java diagnostics screen and its old test runners were **emptied** (≈11 000 lines removed) to be rebuilt cleanly in Kotlin rather than migrated — confirmed beforehand to be wired to no production path.

Still Java, deliberately kept for last: the `proxy` / `proxy/daemon` binder-contract core, `ClusterService`, `AdbLocalClient`, `Platform`, and the largest activities.

## What changed since 1.6.148 (the last beta)

- **Diagnostics emptied.** The ~3 600-line Java diagnostics screen and its DiLink 2/4/5, Mirror and Daemon test runners were removed and replaced by a small Kotlin stub, plus a full sweep of their orphaned layouts and strings. A confirmed-safe teardown — no production path depended on them.
- **8 pure-logic classes migrated to Kotlin**, each validated by its unit test (routing/timing/reuse policies, layout-slot selection, the daemon-start command builder, the lifecycle gate).

## Everything the 1.6.x series brought (for users coming from 1.5.4)

- **DiLink 5 support** — cluster projection on DiLink 5 head units, with signing-wall hardening and a ROM-adaptive uid-2000 daemon path.
- **HUD turn-by-turn (DiLink 3)** — Google Maps / Waze guidance drawn on the windshield HUD over CAN, on arrow-capable firmware.
- **Silent OTA auto-install + relaunch** — a downloaded update installs itself and reopens the app, no manual "Install?" tap (where the daemon is available).
- **Keyboard-free bug reporter** — a 3-step wizard (category → app → issue) that bundles diagnostics and sends them to support in one tap.
- **Layouts** — several apps on the cluster at once, each in a finger-drawn zone; auto-start of a favourite layout, pre-created slots, and a live editor. The main-screen chooser is now collapsed by default so the preview stays large.
- **Headless boot** — projection and the favourite layout can come up at car start with no UI.
- **Wi-Fi hotspot keep-alive (DiLink 3)** — keeps a personal-SIM tether alive across wake-ups.
- **CarPlay full-screen tool** and a **rolling screenshot recorder** that attaches cluster + main captures to bug reports.
- Dozens of cluster-launch, mirror, and daemon-stability fixes root-caused against on-car captures.

## Notes

- **Upgrade:** installs straight over any recent DashCast build. If you are on a pre-`0.2.0` alpha, uninstall first (package rename) — see the README.
- **No daemon protocol change**; DiLink 3 and DiLink 5 projection paths are unaffected.
- Quality gate: release build green, Android lint **0 errors / 0 warnings**, unit tests green.

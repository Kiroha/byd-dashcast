# DashCast 1.9.50-beta

Add **Settings → ADAS pane: hide / restore → Hide the ADAS pane during projection**,
off by default. After a parked acknowledgement, DashCast waits for the requested app to
be resumed on its projection display before applying the recovered Electro masking
sequence: 263 ordered frames per complete pass, guarded retries and maintenance. The
implementation uses DashCast's existing projection ownership and bounded polling; host
adaptations are documented in `docs/NATIVE_ADAS_PANE.md`.

**Hiding the entire ADAS pane also hides its distance alerts and lane warnings.**
Disabling the option, stopping the known projection or choosing **Restore with the full
sequence** requests the recovered restoration sequence. Manual fallback recovery remains
available, and recovery information is retained for another attempt. A sent request does
not confirm the rendered state. In particular, the restoration command forces ancillary
ADAS type 0 rather than restoring a captured prior type.

Initial support remains restricted to the researched **BYD SEAL, Android 10 / DiLink 3,
SX361** firmware `6125f_1for2_USER_SIGN_SX361_202606100404_Q2700` and its exact captured
Android fingerprint. **DashCast's physical masking and restoration remain to be validated
on the parked vehicle.** Other fingerprints are refused. Fix OEM integer reads to support
the inherited typed getter used by this firmware, while retaining the legacy getter on
older SDKs. The interface is translated into all 13 supported languages.

**Install the APK manually over the existing DashCast application without uninstalling.**
The application displays **1.9.50-beta · build 689**. Normal startup replaces older
persistent daemons; the updated proxy uses protocol 27. **DashSat 0.9.9-dev remains
compatible and does not need an update.** No satellite protocol or guidance listener
changes are included.

**1.9.0 remains stable.**

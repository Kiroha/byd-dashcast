# DashCast 1.9.30-beta

DIAG adds **Relevé DiLink — contexte système (lecture seule)**. It runs 14 fixed metadata reads: transport identity, device time, the service listing, selected build/country/region/timezone/locale properties, and package paths/metadata for the two OEM packages. Progress shows the current read, elapsed time and incomplete results. Cancellation preserves the results already received.

Collection uses the already-connected ProxyDaemon Binder without connecting, restarting the helper, retrying or falling back to another transport. A dead Binder or transport timeout produces an explicit partial result. A timed-out Binder call keeps the shared diagnostic gate occupied until the physical call returns, preventing overlapping diagnostic work. The report distinguishes DashCast's app UID from the UID returned by the transport; metadata does not establish effective OEM permissions or authorization.

The collector reads metadata and writes local reports, ZIPs and integrity sidecars. The existing shell transport can also create its temporary PID file. It changes no vehicle setting, opens no OEM activity and submits no QR or authorization code. Empty, denied, malformed and truncated results remain explicit. Results use the device clock, without an independent PC clock comparison. No automatic upload is added.

While parked, with DashCast's existing privileged connection available, open **DIAG → Relevé DiLink — contexte système (lecture seule)** and keep DashCast in the foreground. After completion, use **Fichiers du relevé → Lister / partager** to transfer **context-001.zip** and, if possible, **integrite.json**. Unpack the ZIP into a new collection folder on the PC; retain partial collections and preserve earlier exports. A `.part` file is incomplete. The ZIP contains the per-read results and manifest; the separate integrity file records the finalized ZIP's SHA-256.

Validation: **128 JVM tests across 12 DIAG/ProxyShell suites** passed with no failures or skips. Debug/release lint, the minified release build, platform signature verification and the tagged release-asset scanner passed. Lint retains two existing `UsableSpace` warnings per variant, with no errors. Release versionCode **669**; the release APK is not debuggable and its matching R8 mapping is archived. Vehicle/ROM compatibility and actual collection duration remain unverified; these software checks do not establish zero risk on the vehicle.

# 1.9.67-beta — ADAS masking and restoration ordering

This release aligns ADAS orchestration with the researched BYDcontrol flow. Masking
starts after projection activation, without closing and reopening the projection
inside the masking sequence. A slow pass completes before another pass starts;
one confirmation pass is scheduled five seconds after successful completion.
Power transitions coalesce with pending work instead of cancelling an unfinished
pass.

Full restoration now initializes the OEM `ClusterDebugService` and waits one
second before sending 40 restore frames, AutoContainer command 12, a 1,200 ms
wait, then command 53. Session ownership, cancellation and pinned-daemon checks
also cover this initialization and delay. Stopping projection retains full
restoration, while a newer projection owner cancels obsolete recovery work.

The resumed-target proof now expires after four seconds, accommodating the
existing one-second polling interval and bounded 2,500 ms read. Negative results
and timeouts still invalidate it immediately. DashCast retains its ordered,
bounded 263-frame transport, recovery journal and cancellation guards; this is
an orchestration alignment, not a byte-for-byte clone of another application.

The existing option remains off by default and restricted to the researched
BYD SEAL, Android 10 / DiLink 3, SX361 firmware
`6125f_1for2_USER_SIGN_SX361_202606100404_Q2700`. It hides the **entire ADAS pane,
including its visual distance and lane alerts**. Earlier on-car hide and restore
observations do not validate these revised sequences. Launch, manual restore,
re-hide and Stop cycles still require validation on the parked vehicle. Software
delivery results do not prove that the pane is hidden or visible.

Install **build 706** manually over the current DashCast installation, **without
uninstalling**. The app displays **1.9.67-beta · build 706**. DashSat
**0.9.9-dev** remains compatible; Satellite pairing and guidance protocols are
unchanged. ProxyDaemon protocol **38** and the existing RCC diagnostics are
unchanged. **1.9.0 remains the stable release.**

# DashCast 1.9.43-beta

This prerelease adds a targeted export of original Android init `.rc` source files. The previous service-identity collection preserved metadata but omitted some filenames, quoted declarations and oversized sources. The new collection preserves readable source bytes for offline analysis.

- Open **DIAG → Relevés locaux OEM → Sources init OEM — fichiers complets ciblés** while parked and keep DIAG visible. Transfer `oem-init-sources-001.zip`, including a partial result.
- Scope is limited to `/init*.rc` and direct `.rc` children of the five existing partition `etc/init` and `etc/init/hw` roots. Imports and links are not followed, and collected directives are never executed.
- Reads use the already-connected ProxyDaemon with its existing strict file-read protocol and shared physical-call quarantine. There is no reconnect, bootstrap, privilege change, OEM authentication/policy call or global firmware-policy change.
- Bounds include 2,048 entries, 2 MiB per file, 32 MiB of requested source reads including failed attempts, 64 KiB chunks, and a 128 MiB free-space reserve in addition to pending writes. Acquisition has an 18-minute soft budget, with local finalization within a 20-minute soft session budget. A physical Binder call may remain outstanding beyond its client timeout and continues blocking diagnostics.
- ZIPs include original bytes, exact source paths, per-file SHA-256 values and explicit coverage/failure records. Completed local copies survive later failures. Sharing remains manual; previous QR and service metadata exports remain available.

Sources are read only. DashCast writes its own local copies, metadata and ZIP on primary emulated storage; the existing shell transport may also create its temporary PID file. The collection is non-atomic and does not establish whole-vehicle coverage, physical-medium provenance, OEM authorization or hardware compatibility. POSIX glob expansion precedes the inventory count limits.

Validation: targeted JVM/Robolectric and real-shell fixture checks, independent review, signed release build and publication checks are recorded with the release evidence. Vehicle execution remains to be confirmed on the target firmware.

# DashCast 1.8.1-beta

A code-quality beta on the `switch-kotlin` line. It carries the Kotlin migration forward from the **1.7.0 stable** release — there is **no user-facing change**: behaviour on DiLink 3 and DiLink 5 is identical to 1.7.0.

> This is a tester pre-release from `switch-kotlin`. It is **not** merged into `main` and must **not** be marked as the repository's Latest release.

## What changed since 1.7.0

Six more **pure-logic helper classes** were migrated from Java to Kotlin (migration "batch #2"). Each conversion's behaviour is guaranteed by its existing unit test — the full unit-test suite (**326 tests**) stays green:

- `AppProjectionIndicator` and `MirrorProjection` — app-grid active-indicator and aspect-preserving mirror mapping (UI helpers).
- `PackagePseudonymizer` — HMAC-SHA-256 package pseudonymisation used by the bug reporter.
- `LayoutAutoStartPolicy` and `FissionTeardownPlan` — layout auto-start selection and per-package teardown ordering.
- `OtaInstallCommand` — the uid-2000 staging / install / relaunch shell-command builder for silent OTA updates.

Java ↔ Kotlin interop was preserved verbatim:

- `OtaInstallCommand`'s shell transaction is **byte-for-byte identical** to the Java version (the shell `$VAR`s are escaped, and its unit test asserts the exact command).
- `MirrorProjection` keeps `@JvmField` field access so its Java caller (`MirrorCoordinator`) is unchanged.
- `FissionTeardownPlan` keeps its nested `@Throws` `Operations` interface so the Java `FissionOrchestrator` still implements it.

## Notes

- **No functional change**, no daemon protocol change, no manifest change.
- Quality gate: release build succeeds, Android lint **0 errors / 0 warnings**, **326 unit tests** passing.
- Kotlin now clearly outnumbers Java in the codebase (migration continues toward the daemon-contract and large-activity tiers, kept deliberately for last).

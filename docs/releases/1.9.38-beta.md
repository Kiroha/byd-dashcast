# DashCast 1.9.38-beta (677)

L’export global pouvait terminer en quelques secondes sans fichier : les seuls points de montage ne permettent pas de découvrir un descendant lisible lorsque son parent Android refuse l’énumération. Le manifeste reçu confirme ces inventaires partiels et zéro fichier ; le stderr de `find` était perdu, donc sa cause système précise n’était pas établie.

- L’inventaire garde tous les montages admis et ajoute des points d’entrée Android connus, les stockages de l’utilisateur courant et les chemins APK indiqués par PackageManager via le daemon SHELL. Les chemins et leurs parents passent les mêmes contrôles de stockage avant leurs métadonnées ou leur lecture. Une APK connue peut être lue même si son répertoire parent refuse l’énumération.
- Les inventaires incomplets restent signalés comme tels. Une reprise les retente une seule fois par exécution, en conservant les fichiers déjà vérifiés. Les sessions de la version précédente sont réinventoriées une fois pour appliquer ces nouvelles entrées.
- Le rapport de bug existant conserve le bilan final, les compteurs et des incidents bornés ; les erreurs de `find` sont capturées sans contaminer les noms de fichiers et limitées à 2 Kio avant leur transport. Une collecte vide est explicitement affichée comme vide.

La collecte reste limitée aux fichiers ordinaires lisibles du stockage interne attesté, via le daemon ADB/SHELL UID 2000. SD, USB, stockage adopté, interfaces et arbres propres au collecteur restent exclus. Les sources sont uniquement lues ; les archives et métadonnées sont écrites sur le stockage interne. Les montages système dont la provenance physique ne peut pas être établie restent exclus ; aucune sécurité, permission ou propriété OEM n’est modifiée.

La lecture d’un descendant inconnu d’un parent non listable reste impossible sans référence préalable. Les graines absentes ou inaccessibles restent signalées comme non établies. Il ne s’agit pas d’une image physique complète et la collecte reste non atomique. La validation matérielle de cette version reste à effectuer, véhicule stationné et DIAG visible.

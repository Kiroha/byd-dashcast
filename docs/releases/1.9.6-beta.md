# DashCast 1.9.6-beta — Independent HUD and cluster guidance

**SEAL without HUD:** open **Settings → Navigation guidance**, turn **Enable
guidance ON**, **HUD OFF** and **Instrument cluster ON**. Allow notification access
for DashCast, then start navigation in Maps/Waze. This uses the cluster's dedicated
output without sending HUD/CAN commands.

Pre-release from `feat/hud-2.0`, versionCode **645**. **1.9.0 remains the stable release.**

## Choose where navigation guidance appears

Settings now has a master switch and separate windshield-HUD and instrument-cluster
switches. You can select **both**, **HUD only**, **cluster only**, or **all off**.
Turning off the master preserves the individual choices; existing installations
default to both outputs.

Cluster-only uses the OEM AutoContainer navigation channel independently of HUD
presence or CAN activation. HUD-only sends CAN guidance without activating or
sending navigation content to AutoContainer. The OEM Amap relay runs only when both
outputs are enabled because its receiver also writes CAN.

Changing a setting clears the previous session on the serial navigation writer.
The next fresh navigation notification resumes the chosen outputs, even when its
text is unchanged. Old notifications are not replayed from Settings; stale guidance
is cleared by the watchdog. These settings control navigation instructions; app
projection has its own controls.

The switches, help text and notification-access banner are translated in all
**13 app languages**. The banner is hidden when all guidance is disabled.

## Fix native files in OEM exports

**Diag → BYD APK Extraction** now preserves extensionless ELF executables such as
`fissiond` instead of treating them as text. Extensionless logs and explicitly named
text files remain redacted. The previously collected OEM APKs were intact; damaged
native executables need a new export from this corrected build if required.

## Installation and OTA test

**Android 10 / DiLink 3 users on 1.9.4-beta or older must install this APK manually**
over the existing app. **Do not uninstall first**: this preserves settings and
diagnostic pairing. Those builds reject the update before the installer starts.

**1.9.5-beta already contains the certificate fix.** Updating from 1.9.5-beta to
this release lets testers verify the corrected OTA download and installation on a
vehicle. End-to-end OTA installation has not yet been confirmed. If it fails,
install `DashCast-v1.9.6-beta-release.apk` manually while parked and send a bug report.

## Validation and limits

**812 tests / 165 suites**, no failures, errors or skips; **release lint 0 issues**;
release assembly successful. New coverage exercises actual controller/listener code
against a recording daemon Binder, including output isolation, switching during an
in-flight frame, cleanup, identical content after switching and cluster staleness.

This exact APK has not been tested in a vehicle. Cluster rendering on the SX361
SEAL remains to verify. HUD-only and both-output rendering, including any indirect
effect of shared CAN registers on the cluster, need a HUD-equipped vehicle.
SOME/IP profiles remain inactive pending OEM receiver validation.

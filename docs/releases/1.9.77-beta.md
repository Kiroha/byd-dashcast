# 1.9.77-beta — Read-only OEM consultation and Brazilian Portuguese

**Install the signed release APK manually over DashCast, without uninstalling or
clearing application data. This prerelease is version 1.9.77-beta / build 717.**
The stable release remains 1.9.0. ProxyDaemon protocol 44 is retained; the higher
build number refreshes persistent daemons. Before cluster diagnostics, verify that
the running ProxyDaemon reports build **717**. Protocol 44 alone does not identify
the updated daemon.

## Read-only OEM consultation

The OEM selection query can now consult a trusted, dormant Android IVI recovery
session retained in historical quarantine. The query uses an isolated helper and
checks eligibility again before admission. Live failures, untrusted journals,
recorded helpers, native-mode debt and commands or recovery already in progress
remain blocked.

The last consultation result or refusal stays visible below its button, separately
from the historical status refreshed by polling. Pending interface callbacks are
invalidated when the connection or page changes. These messages are available in
all **14 supported application languages**.

Consultation does not load a theme, restore the factory display or clear recovery
debt. The journal and visual observations are retained. A receipt reporting factory
selection does not establish that the normal BYD instruments have returned.

## Brazilian Portuguese

Brazilian Portuguese is now available in the application and its manual, including
the language picker, diagnostic messages and report-language selection. Existing
language choices remain available.

## Recovery and validation limits

A manual Restore requested during consultation waits until the owned query helper
is positively reaped. If that cannot be confirmed, restoration remains pending and
requires further diagnosis. Do not clear data, restart the daemon or downgrade to
bypass that state. After a backward clock adjustment, the result panel can retain
an older pending message; another manual consultation after the helper finishes
obtains a fresh receipt.

The retired full-screen application profile remains **recovery-only**. Its new
load and confirmation actions stay refused, and the rewritten QML prototype remains
an offline development artifact absent from the APK. **This prerelease does not
enable a new full-screen Waze test.** Existing recovery journals and factory
restoration requirements remain in force.

DashCast Satellite pairing, guidance compatibility and native video contracts are
unchanged. Host checks and stock Android emulator checks do not validate the BYD
ROM, shipped ARM native libraries, hardware decoding or vehicle recovery. No vehicle
commands were sent during release preparation. Any sensitive validation requires a
stationary vehicle in a suitable test context, with normal OEM instruments and
alerts visually verified.

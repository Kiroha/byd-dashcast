# DashCast 1.9.44-beta

Adds support for DashSat's explicit, bounded video compatibility test. A visible TEST PATTERN label
appears before the first image and stays visible during the test. Receiver history and manually
transferred sender diagnostics distinguish synthetic reference video from captured application video.

Use with DashSat 0.9.8-dev: while parked, select an app, choose **Test video compatibility**, accept
Android screen-sharing consent, leave the shared app open on the Tbox, then return to DashCast and
open the video viewer. The test uses known synthetic H.264 frames through the existing WebRTC
transport; it sends no app images. It ends automatically. Afterwards, send diagnostics to DashCast
and generate a bug report. Starting normal sharing requires new Android consent.

This is a diagnostic release, not a confirmed fix for the vehicle's black video. A reference image
only establishes that this known stream can be displayed; it does not establish hardware decoding,
normal ABRP video compatibility or lower vehicle CPU/GPU use. Guidance, pairing, capture consent,
normal video formats, the installed WebView and OEM display ownership are unchanged.

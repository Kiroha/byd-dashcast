# DashCast 1.9.15-beta — Roundabout traffic side

Roundabout guidance can now use the circulation direction for the selected traffic
side instead of retaining a source direction that is unsuitable for the country.
The setting changes presentation for both the HUD and instrument cluster, with
local navigation or Satellite guidance.

**Vehicle APK: versionName `1.9.15-beta`, versionCode `654`.** Install manually over
the existing vehicle app, **without uninstalling**, to keep settings and pairing.
The application displays this version and build in Settings. Publication continues
from `feat/hud-2.0`; **1.9.0 remains the stable release**.

## Choose roundabout direction

While parked, open **Settings → Navigation guidance → Roundabout direction**:

- **Direction supplied by navigation** — default for existing installations;
  preserves the deployed source mapping without guessing the country.
- **Right-hand traffic (France)** — counter-clockwise circulation. Choose this
  option for the reported roundabout display in France.
- **Left-hand traffic (United Kingdom)** — clockwise circulation.

Traffic side is independent of steering-wheel position. The saved choice applies
to the **next fresh guidance update**. It does not replay a stored route or renew
its freshness timer. Numbered roundabout exits keep their exit number and every
distance remains unchanged. Audited generic roundabout shapes keep their turn
geometry. Ordinary left/right turns, arrivals, route time and ETA stay unchanged.

Labels and help text are available in all **13 existing application languages**.
Unconfirmed generic variants **23/24** remain untouched. Static and JVM checks do
not establish identical HUD/cluster rendering on every model or firmware.

## Satellite compatibility

Compatible with **[DashCast Satellite 0.5.0-dev](https://github.com/Kiroha/dashcast-satellite/releases/tag/v0.5.0-dev)**.
The existing six-digit pairing and guidance **protocol v1** are preserved;
no companion update is required for this traffic-side setting. Existing receiver
certificate identity and pairing credentials remain valid. IPv4 hotspot recovery,
visible pairing failures and normal authenticated WSS upgrades from earlier
prereleases are retained.

For a new pairing, connect the Tbox to the vehicle hotspot, open
**Settings → Navigation guidance → Satellite device → Pair a device** in DashCast,
then enter the six-digit code in Satellite before its original two-minute window
expires. **Continue on Tbox** hides the code while keeping that countdown running;
**Cancel** ends the pairing window.

Satellite needs notification access on the external device. In DashCast, enable
the receiver, **Use satellite guidance**, and the desired HUD/cluster outputs.
Authenticated connection and available, fresh guidance remain separate states.
The traffic-side choice only changes the rendering snapshot; it does not alter
source selection, authentication, expiry or the Satellite wire format.

## Vehicle validation

Physical roundabout rendering for this new choice **still needs validation in the
vehicle**. Record the vehicle model, ROM/firmware, selected traffic side and enabled
outputs. Configure the choice while parked, then use a suitable test context to
compare source mode, right-hand traffic and left-hand traffic with numbered and
generic roundabouts. Check exit number and distance, ordinary left/right turns,
route stop/expiry, and local versus Satellite guidance independently.

Earlier OEM evidence concerns DiLink 3 / Android 10 / API 29; it is not proof of
compatibility for every firmware. This release introduces no new OEM transport,
permission or vehicle-control command.

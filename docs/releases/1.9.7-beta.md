# DashCast 1.9.7-beta — Maps Morphe navigation fix

**Fix missing guidance with Maps Morphe.** The SEAL pilot's Google Maps uses
`app.morphe.android.apps.maps`. DashCast 1.9.6-beta rejected this package before
reading its navigation notifications, so no guidance reached the instrument
cluster. This release recognizes that exact package through the existing Maps
notification pipeline.

Pre-release from `feat/hud-2.0`, versionCode **646**.
**1.9.0 remains the stable release.**

## Test on a SEAL without HUD

1. Open **Settings → Navigation guidance**: **Enable guidance ON**, **HUD OFF**,
   **Instrument cluster ON**.
2. Allow notification access for DashCast, then start navigation in Maps Morphe.
3. Check the cluster's direction and distance, updates during navigation and
   clearing when the route ends. If the cluster stays empty, send a bug report
   from Diag while navigation is active and describe what you observed.

The reported trial had notification access and an active Maps route. Its last
recorded destination choice was both outputs; use cluster-only for this SEAL.
The package rejection is fixed, but **physical rendering still needs vehicle
validation**. Tests use synthetic navigation notifications and do not establish
the exact format of every notification from Maps 26.33.

## What changes

Add Maps Morphe to the explicit navigation package list used for new posts,
listener reconnection, source handover and notification removal. Similarly named
unknown apps remain excluded. Preserve the existing parsers, navigation payloads
and independent HUD/cluster controls.

Cluster-only continues to use AutoContainer without HUD/CAN commands or the OEM
Amap broadcast, including start and stop. Guidance settings remain translated in
all **13 app languages**; this patch adds no user-facing strings. SOME/IP profiles
remain inactive pending receiver validation.

## Installation

**Android 10 / DiLink 3 users on 1.9.4-beta or older must install manually** over
the existing app. **Do not uninstall first**: this preserves settings and pairing.
Those builds reject the update before installation.

Users on **1.9.5-beta or newer**, including 1.9.6-beta, can test the corrected OTA
path. End-to-end installation still needs vehicle verification. If the installer
does not start, install `DashCast-v1.9.7-beta-release.apk` manually while parked.

## Validation

**815 tests / 165 suites**, no failures, errors or skips; **release lint 0 issues**.

The regression reproduces zero AutoContainer frames before the fix, then checks
cluster-only activation, a right-turn / 200 m payload and route clearing after
the fix. Additional coverage checks source handover and exclusion of unknown
packages resembling Maps Morphe. Vehicle rendering remains unverified.

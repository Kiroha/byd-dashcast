# DashCast 1.9.26-beta

Extend the DIAG **Export system files** collection for the DiLink reverse-engineering work. The targeted collector now includes 22 additional dependencies, five Fission/Qt paths, and bounded candidates for the `auto` HAL and Bionic/media components. Exact path probes reduce unrelated neighboring files while preserving visible progress, cancellation, provenance, and partial-result reporting.

The export remains a targeted collection of readable files, not a complete firmware image. It reads selected system files and writes ZIPs, manifests, and temporary files locally; the ProxyDaemon keeps its normal connection lifecycle. It adds no permissions and invokes no vehicle APIs. Availability still depends on this ROM's filesystem permissions, and the HAL/JNI/navigation native links remain under analysis.

For a new collection, use **DIAG → Export system files** while parked. Copy every ZIP and the final `manifest.json` beside them into a new `Dilink3-system-P5` folder. A per-volume `manifest-volume.json` is not the final session manifest. Keep previous exports separately.

Validation: **97 DIAG JVM tests** passed. Debug and release builds, debug and release lint, release signing verification, and the release-asset scanner passed. Lint retains two `UsableSpace` warnings. Release APK versionCode **665**; this pre-release does not change stable **1.9.0**.

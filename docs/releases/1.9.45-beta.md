# DashCast 1.9.45-beta

This prerelease adds a targeted passive bootstrap and native-service identity export. The complete accessible init-source collection preserved a `strategyservice` restart reference but did not establish the active bootstrap files or native publisher. This follow-up collects bounded process metadata and a closed set of original file candidates in one local ZIP.

- While parked, open **DIAG → Relevés locaux OEM → Démarrage et identité du service OEM**, keep DIAG visible, and share `oem-bootstrap-001.zip` through **Fichiers du relevé → Lister / partager**. Partial results remain useful; previous exports stay available.
- Capture boot-selector/hardware properties and at most ten deduplicated numeric PIDs: namespace PID 1, the negotiated daemon PID, and up to four exact names each for `init` and `strategyservice`. Per-PID stat/starttime brackets detect reuse, disappearance and name changes. Raw NUL-containing proc bytes and link observations are preserved as Base64; names and links do not establish Binder publisher attribution.
- Copy only 28 literal bootstrap, init, native-service, startup-wrapper and conditional Fission cell2 candidates. Symlinks, nonregular files and noncanonical paths are refused. Source metadata runs in batches of at most four paths, with copies/checkpoints between batches so earlier results survive a later timeout. Collected scripts are never executed and no proc-root, executable link, import or property-derived path is followed.
- Reuse the already-connected UID-2000 ProxyDaemon, existing strict-read protocol and shared physical-call quarantine for every metadata/chunk operation. A timed-out or malformed operation ends acquisition; late calls keep diagnostics blocked and cannot update exports. There is no reconnect, bootstrap, daemon/protocol/permission change, root/SELinux workaround, OEM authentication/policy call, backend request or global-export policy change.
- Bounds include 40 KiB raw / less than 64 KiB encoded metadata per PID, 1 MiB aggregate metadata, 8 MiB per source, 32 MiB aggregate requested source bytes including failed attempts, 64 KiB chunks, and a 128 MiB local reserve plus pending writes and ZIP allowance. Acquisition/session have 18/20-minute soft budgets; a physical call can outlast its 35-second client wait.
- **Arrêter les lectures** stops consumption after the current call returns and preserves earlier completed evidence. Local ZIP/hash finalization is shown separately. Completed copies survive later failures, and a finished ZIP survives a later integrity-sidecar failure. Manifests distinguish access denials, missing candidates, truncation and unobserved results.

Sources are read only. DashCast writes its own local files and ZIP on primary emulated storage; the existing shell transport may also create its temporary PID file. Sharing remains manual. This live collection does not establish full vehicle coverage, source authenticity, host namespace identity, active boot selection, OEM authorization, QR approval or hardware compatibility. Conditional cell2 paths are static-evidence candidates whose presence and readability remain unproven.

Validation: 101 focused JVM/Robolectric tests passed (29 new bootstrap checks and 72 existing collector, transport, metadata and session regressions), including real Linux shell/proc fixtures. A signed minified release build completed with all 47 tasks forced to execute; fresh vital lint reported no issues. Independent review and publication checks are recorded separately with the release evidence. Target-vehicle execution remains pending.

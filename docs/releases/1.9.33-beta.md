# DashCast 1.9.33-beta

Adds bounded first-frame diagnostics for received satellite video: selected H.264 profile, level and
packetization mode when explicitly available; nullable keyframe/RTCP/decode-time counters; and
video element, playback promise and remote track state. Final playback failures retain a scalar
sample even when the viewer closes before the next one-second observation.

The existing manual DashSat diagnostics transfer accepts an optional negotiated details extension
containing up to four historical sender attempts. Legacy senders and snapshots remain supported.
No raw signalling, identifiers, addresses or content are added to support reports. No additional
polling, codec fallback, offscreen decoder or change to guidance freshness is introduced.

Includes the firmware/APK export changes from 1.9.32-beta. This release improves evidence for the
black-image investigation; it does not claim that decoding or vehicle performance is fixed.

Validated with 1265 JVM tests, 38 browser-script regression tests, debug assembly and Android lint
(no errors; four existing APK/firmware export UsableSpace warnings). Android 10 optimized-release/runtime
checks are performed against the final frozen APK. Vehicle first-image validation remains pending.

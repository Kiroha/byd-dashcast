# DashCast 1.9.49-beta

Add **Settings → ADAS pane: hide / restore**, separate from the existing **ADAS Window Fix**.
The two actions send manual requests to the native OEM pane. Hiding the **entire pane also
hides its distance alerts and lane warnings**. Each hide requires a parked acknowledgement.

Before sending a hide request, DashCast checks the researched firmware and OEM receiver,
reads the original input and saves recovery information durably. A failed check or save
prevents the request. Restore uses that saved input and remains available without the proxy
reader; recovery is retained so it can be retried manually. Requests are never replayed on
boot, resume, reconnect or a timer. A “request sent” result is not confirmation of the
rendered state. The interface is translated into all 13 supported languages.

Initial support is restricted to the researched **BYD SEAL, Android 10 / DiLink 3, SX361**
firmware `6125f_1for2_USER_SIGN_SX361_202606100404_Q2700` and its exact captured Android
fingerprint. Other fingerprints are refused. The maintainer has confirmed Electro's hide
on this vehicle; **DashCast's own hide/restore pair, especially restoration, still requires
parked-vehicle validation**. Restoring the input returns control to the normal OEM display
conditions and does not force the pane visible.

Also align the OEM diagnostics menu regression check with its existing cluster context entry.
The previous satellite decoder crash fix and cluster surface recovery are retained.

Install this release over the existing DashCast application without uninstalling.
**DashSat 0.9.9-dev remains compatible and does not need an update.** No satellite protocol
or guidance listener changes are included. The application displays **1.9.49-beta · build 688**.

**1.9.0 remains stable.**

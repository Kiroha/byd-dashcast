# 1.9.80-beta — Guided cluster recovery and explicit maintenance restart

**Install this signed release APK manually over DashCast, without uninstalling
or clearing application data. Check version 1.9.80-beta / build 720 in the app.**
The stable release remains 1.9.0. This build refreshes persistent daemons; the
new recovery workflow requires the connected ProxyDaemon to report protocol
**45**. An older daemon cannot offer the integrated restart.

## A clearer cluster diagnostics page

Open **Diag → DashCast dashboard**. The main page now shows the current state,
the applicable next action and a fixed **Restore cluster** button. Previous
experiments, native controls and raw technical receipts stay under **Show
details and previous tests**. Instructions and recovery prompts are translated
into all 14 supported languages.

## Verified RCC preparation before restart consent

**Restore cluster** reads the connected session and closes DashCast's projected
resources. It does not reboot immediately. Follow the parked/recovery and RCC
preparation prompts. The existing fresh exact-own selection and
`RESOURCE_IS_SAME` retirement requirements remain in force; an unresponsive Qt
consumer or an unresolved helper can prevent preparation. Missing proof is a
refusal, never permission to move an unidentified file.

Only the journal-owned DashCast test RCC is moved into a hidden recovery
directory, preserving its bytes. Fresh checks verify the preserved hash and
file/directory identities, the absence of its original lookup name and a
successfully enumerated lookup directory with no remaining DashCast-prefixed
entry. Factory and third-party resources are preserved. A failed, incomplete or
changed result blocks restart.

After these checks pass, a separate popup asks you to confirm that the vehicle
is **immobilized in P with the parking brake applied**, and to accept temporary
interruption of the screens and ADB. **Accept restart** authenticates the local
ADB connection, repeats the file/session checks and verifies the researched
Android 10/API 29 runtime cohort using exact `libBydCluster.so` and `fissiond`
hashes. Only then can one fixed ADB service request, `reboot:fission-all`, be
sent. Canceling the popup sends no restart. No country setting or MCU
configuration is changed.

Both daemon and application record durable intent before dispatch. Double
clicks, timeouts, disconnections and page/process recreation do not automatically
repeat a restart. An unused confirmation expires; a consumed restart intention
remains pending. A timeout or returning ADB connection does not mean the cluster
has recovered. After reconnecting, use **Restore cluster** to verify the default
selection and answer the question about the physical BYD instruments and
alerts. Completion requires a changed boot and the existing recovery evidence
plus your visual confirmation; a correlated historical receipt covers the
crash window between daemon completion and application acknowledgement.

These filesystem checks observe defined checkpoints. They cannot prevent an
independent privileged process from changing files afterwards, and they do not
guarantee physical cluster recovery.

## Test scope and compatibility

**The complete in-app restart and failed-QML recovery sequence still needs
validation on the parked vehicle.** The historical external ADB maintenance
trial succeeded from a normal OEM display; it is not proof that this integrated
workflow recovers every failure. No vehicle command was issued during development
or release preparation. User confirmation is an assertion, not a movement sensor.

The new blank/full-screen RCC research remains offline and is **not available
for loading in this APK**. The retired unsafe full-app profile stays
recovery-only. This release does not enable a new cluster theme or make it ready
for road use. Do not clear recovery data or reinstall an old APK to bypass a
refusal.

DashSat pairing, guidance and video protocols are unchanged. Existing Satellite
compatibility is retained; no new end-to-end DashSat/vehicle compatibility claim
is made by this release.

# DashCast 1.9.41-beta

DashSat video startup diagnostics can now include bounded observations of the actual hardware
H264 output: observed SPS/PPS/IDR headers, fixed SPS profile/constraint/level bytes and SDK image
dimensions. This distinguishes encoded output from SDP negotiation and RTP traffic without
exporting media content. Existing manual Send diagnostics/received ACK and bug reports carry the
evidence, including after returning from CarPlay.

This requires DashSat 0.9.6-dev for the new evidence. Older companions and receivers retain the
previous diagnostics contract. Pairing, guidance, capture and decoder behavior are unchanged.
This is an investigation build, not a confirmed fix for the black first image on WebView 74.
No system WebView, BYD application, firmware or OEM permission is changed.

Validation: 44 targeted receiver/protocol/report tests pass; the extended ART/TLS fixture compiles.
Final release checks are recorded with the frozen artifacts. Vehicle first-image decoding, latency
and CPU/GPU savings remain unverified.

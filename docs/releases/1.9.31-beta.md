# DashCast 1.9.31-beta

DIAG’s **Export système — complet ou complément DiLink P15** now offers a small **Complément DiLink P15** collection alongside the existing full SYSTEM export. The complement probes 15 fixed paths: the Fission/diagnostic executables referenced by the collected init configuration, `licenseCheck`, and the two ABI paths for `libfission_license.so` and `libssl.so`. It does not scan framework, XML, native-library directories or runtime classpaths. The Fission licence dependency is separate from OEM QR authentication.

Each fixed path is inspected independently under the existing ProxyDaemon and app identities. A shell refusal remains in the manifest even if the app can read the file. Denied or unknown metadata is not treated as an empty file. Only allowed canonical paths with a regular-file type and positive known size are copied, with canonical/type/size rechecks before reading. This does not grant additional permissions or guarantee recovery of protected files. The new profile, requested path list, identity-specific discovery results, copied-file SHA-256 and before/after build context are recorded in the manifests. Its separate export directory also preserves the profile when reopening DashCast after an interruption.

Existing progress, elapsed/stall indicators, cancellation, standalone ZIP volumes and manual file sharing are reused. Completed ZIPs remain available after a partial result or cancellation. Firmware files are read only; local reports, ZIPs, bounded temporary inventory snapshots and the existing daemon bootstrap/PID files may be written. The existing connection may start ProxyDaemon or replace an obsolete instance. No collected binary is executed, no OEM service method is invoked and no vehicle setting or permission is changed. A partial result may contain only metadata if all requested files remain inaccessible.

While parked, open **DIAG → Export système — complet ou complément DiLink P15 → Complément DiLink P15**. Keep DashCast in the foreground and watch the progress panel. When finished, open **SYSTEM P15 export files → List / share files** and transfer every finalized `system-*.zip` plus the separate **`manifest.json`** from the same export directory. Preserve a partial collection and its manifest too. The manifest inside a ZIP is `manifest-volume.json`; the separate session `manifest.json` contains final coverage. Unpack into a new PC folder such as `Dilink3-system-P15`, preserving earlier exports. `.part` files are incomplete.

Validation: independent final verification passed **134 JVM tests across 12 DIAG suites**, with no failures, errors or skips. The implementation checks also passed 74 tests across six suites, including ten complement-specific tests. Debug/release lint and the minified release build passed. Each lint report retains the two existing `UsableSpace` warnings and no errors. Graphify was updated using AST extraction. Release versionCode **670**. Software checks and vehicle/ROM validation are reported separately; desktop checks do not establish hardware compatibility or zero risk on the vehicle.

# DashCast 1.9.53-beta

Add **Inspect existing OEM ADAS logs** to **Diag → ADAS targets (read-only snapshot)**.
This separate manual action checks fixed OEM log locations for existing target callbacks
and reports accessible files, matching records and explicit access/error outcomes. It helps
test whether Android can see the cluster's historical target logs when the raw-property
snapshot does not return usable targets.

Collection reads bounded file tails and retains only metadata and matching target callbacks.
It does not enable OEM logging, open an SPI device, subscribe to target data or change vehicle
settings. Opening the screen or generating a bug report does not start an inspection. Both
normal and fallback bug reports include the latest retained inspection result and diagnostic
journal without performing another read.

**This is a historical log visibility test.** Matching callbacks do not establish live target
access, sensor freshness, complete surroundings or a working 360-degree view. Missing matches
in bounded file tails do not prove that target data is absent elsewhere. File visibility,
effective permissions, active target feeds and vehicle compatibility remain unverified.

To test with the vehicle parked:

1. Install the APK over the existing DashCast application without uninstalling, then open it.
2. Open **Diag → ADAS targets (read-only snapshot)** and acknowledge the stationary test.
3. Tap **Inspect existing OEM ADAS logs** and wait for its outcome.
4. Generate a bug report to include the retained result.

# DashCast 1.8.3-beta

A code-quality beta on the `switch-kotlin` line. It carries the Java → Kotlin migration forward from 1.8.2 — there is **no user-facing change**: behaviour on DiLink 3 and DiLink 5 is identical to 1.8.2.

> This is a tester pre-release from `switch-kotlin`. It is **not** merged into `main` and must **not** be marked as the repository's Latest release.

## What changed since 1.8.2

**12 more classes migrated from Java to Kotlin**, each guaranteed by its unit test — the full unit-test suite (**324 tests**) stays green.

- **`util/concurrent/` is now 100 % Kotlin** (migration batch #3): `WorkerLifecycleController`, `BoundedSerialExecutor`, `DeathLease`, `SingleFlight`, `CloseableResourceSlot`, `LatestValueDispatcher`.
- **`system/CanBatchOperation`** (immutable CAN write + `Writer` dispatch) and **`ui/main/DashboardSelectionTracker`** (boot-adoption generation tracker).
- **Four `proxy/daemon` pure-logic helpers**: `TaskMoveResult`, `TaskLaunchRecovery`, `FissionWatchdogRegistry`, `FissionWatchdogPolicy`.

Concurrency was preserved verbatim (`@Synchronized`, `@Volatile`, `Atomic*`, `CountDownLatch`), and the Java-facing API was preserved for the sensitive consumers that keep these on the hot path — `ProxyClient`, `MirrorDaemon`, `MapNotificationListenerService`, `Phase4TaskVerbs`, `VoskTranscriber`:

- single-method callbacks became Kotlin `fun interface`s so the existing Kotlin SAM lambdas still compile;
- boolean status accessors stayed `is`-properties so the Java callers keep `isActive()` / `isLeader()`;
- defensive-copy getters and `@Throws` contracts were kept intact.

## Notes

- **No functional change**, no daemon protocol change, no manifest change.
- Quality gate: release build succeeds, Android lint **0 errors / 0 warnings**, **324 unit tests** passing.
- The codebase is now clearly majority Kotlin (≈ 61 %). Remaining Java is deliberately kept for last: the binary daemon wire contract, the large system services (`ClusterService`, `AdbLocalClient`, `Platform`, `CanBusController`) and the big activities.
